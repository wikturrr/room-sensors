# Official references used for this Git iteration

Checked on 4 November 2026. The course guides give project-specific exercises;
these sources define the tools' behaviour. The references are primary Git and
GitHub documentation, not a requirement to read every manual before starting.

| Key | Official reference | What it supports |
|---|---|---|
| R01 | [gitignore](https://git-scm.com/docs/gitignore) | Patterns, untracked files, and limits of ignoring. |
| R02 | [gitattributes](https://git-scm.com/docs/gitattributes) | Text detection, newline rules, and renormalisation. |
| R03 | [git init](https://git-scm.com/docs/git-init) | Starting a repository and naming its initial branch. |
| R04 | [git config](https://git-scm.com/docs/git-config) | Local settings and commit identity. |
| R05 | [git add](https://git-scm.com/docs/git-add) | Staging contents and dry-run previews. |
| R06 | [git commit](https://git-scm.com/docs/git-commit) | Recording the index with a message. |
| R07 | [git status](https://git-scm.com/docs/git-status) | Staged, working-copy, untracked and ignored states. |
| R08 | [git check-ignore](https://git-scm.com/docs/git-check-ignore) | Matching rules and diagnostic exit codes. |
| R09 | [git diff](https://git-scm.com/docs/git-diff) | Working/index/history comparisons and whitespace checks. |
| R10 | [git log](https://git-scm.com/docs/git-log) | Inspecting history and graphs. |
| R11 | [git restore](https://git-scm.com/docs/git-restore) | Restoring the index or working tree. |
| R12 | [git rm](https://git-scm.com/docs/git-rm) | Removing an index entry with `--cached`. |
| R13 | [git clone](https://git-scm.com/docs/git-clone) | Creating a working copy from shared history. |
| R14 | [git remote](https://git-scm.com/docs/git-remote) | Naming and inspecting remote destinations. |
| R15 | [git push](https://git-scm.com/docs/git-push) | Sharing commits and setting an upstream. |
| R16 | [git pull](https://git-scm.com/docs/git-pull) | Fetch/integration and fast-forward-only policy. |
| R17 | [Adding existing local code to GitHub](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github) | Empty remote import and Git 2.28 branch syntax. |

| R20 | [Install Git](https://git-scm.com/install/) | Platform-specific installation options. |
| R21 | [git rev-parse](https://git-scm.com/docs/git-rev-parse) | Checking the top-level directory. |
| R22 | [git revert](https://git-scm.com/docs/git-revert) | Reversing a commit using a new commit. |
| R23 | [git switch](https://git-scm.com/docs/git-switch) | Creating and selecting branches. |
| R24 | [Pull requests](https://docs.github.com/en/pull-requests/reference/pull-requests) | Hosted proposals and code review. |
| R25 | [git branch](https://git-scm.com/docs/git-branch) | Local branch management and deletion safeguards. |
| R26 | [git merge](https://git-scm.com/docs/git-merge) | Fast-forwards, conflicts, resolution and aborting. |
| R27 | [git ls-files](https://git-scm.com/docs/git-ls-files) | Listing tracked paths. |
| R28 | [git check-attr](https://git-scm.com/docs/git-check-attr) | Inspecting effective text and newline attributes. |

No credentials or hosting account are needed to open these public documentation
pages. The Git exercises are written for local practice first; hosted actions
require your own approved repository and authentication.
